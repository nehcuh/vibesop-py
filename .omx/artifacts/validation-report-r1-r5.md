## 3. 分层结论

### 3.1 产物层:零增益,kill criteria 触发

n=4 一致支持:**捆绑技能处理(技能×触发率×准确率)在产物质量上无可测增益**。强模型下,无论规格完整(R3 cart_lib)还是规格留白(R5 教具),结果层都不分离。

- R5 预注册 5 预测:P2(D1/D2 平手)精确命中;P3(教学法显性胜出)未成立;P5 差 0。
- 唯一两轮方向一致的过程差异——**主动自测**——出现了两次(R3/R5),从未转化为产物差异。

### 3.2 成本层:不稳健,撤回成本结论

R1 1.8× → R2 交叉 → R3 1.9× → R5 0.82×(反向)。墙钟不可作为判据;早先"treatment 有可见成本"的说法作废。

### 3.3 基建层:全绿

容器/评分/treatment 三验/预注册流程全部跑通;顺带修出一个真 P0(`vibe init` null 键崩溃,e0c9a6f)与若干容器坑(grok auth 15h 过期、`--always-approve` 必需、tar uid/git safe.directory)。

### 3.4 路由层(R4 行动项,独立于 A/B):真实问题,已修复 [executed]

A/B 的前提是"注入该发生时发生、不该发生时不发生"。精度审计(2026-08-29)发现**负侧失守**:聊天/评审/翻译类查询 5/7 误注入(恒 82% 置信度)。根因四个(v1 提示词无 no-match 出口 / 非结构化回复硬编码置信度 / 缓存污染 / kimi -p 信封未解包),6 commits 全修:

- 修复后实机:同 7 探针 0/7 误报,正例 3/3
- held-out 资产(22 负+8 正,rule-of-three 门):首轮 3/22 → 提示词加固后 2/22,残余已通道归因(multi-intent 检测器 / keyword 层)归 P3
- 修复本身经 kimi 五路对抗复审,round-2 must-fix 全清;CI 全绿(job 级)

## 6. 补记（2026-08-29，用户讨论后精炼）：harness 假说

用户洞察:"harness 做得好的,对技能依赖度可能没有那么高"——正确,机制精炼为:

**技能 = 提示词层的规范执行;好 harness = 结构层的规范执行;两者并存时结构层赢。** R3 即证据:技能塑形了过程(transcript 可见),但强模型默认行为等价,产物不分离。

完整矩阵(四次实验只覆盖了一格):

| | 技能价值 |
|---|---|
| 差 harness + 技能 | **主动伤害**(路由审计 5/7 误注入) |
| 好 harness + 强模型 + 方法论技能 | **冗余**(R1/R2/R3/R5 四连平手) |
| 好 harness + 模型不具备的信息型技能(组织 runbook/冷门坑/项目约束) | **唯一存疑价值格,未测** |
| 弱模型 / 50+ 技能规模 / 长时程 | 未测;R4 与 R3 结论均指向"要显形需这些条件" |

现场证据第三例(2026-08-29):用户纯讨论性提问触发 multi-intent squad 编排(tester/architect/documenter)——HN02 残留通道复现,印证"差路由层下技能编排是负资产"。
