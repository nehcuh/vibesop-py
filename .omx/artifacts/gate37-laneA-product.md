# Gate37 Lane A 评审报告：技能评价体系（产品/用户价值视角）

## 0. 总判断

四层提案分析上完整，但**用户价值密度排序恰好与层号相反**：L1 最便宜、最贴近决策时刻；L3/L4 最重、离用户最远。L2 方向正确但指标集过度设计，fire→成功率、劫持率按现状数据资产做出来会是"自欺数字"或"看不懂的列"。建议：**L1 先行 + L2 大幅瘦身，L3 降级为按需工具，L4 移出产品范围**。

核查发现：`vibe skill list`/`stale`/`cleanup` 已有健康表面（skill_commands.py:97 已输出 "all healthy" 汇总行）；gate36 verifier 自我声明只测"触发召回"不测"内容质量"（promote_verifier.py:11-15）；gate31 骨架 TODO 槽位本身就是可 lint 的空壳信号；FeedbackCollector 只记显式反馈（discovery.py:46 注释自认），outcome 信号稀疏。

## 1. 逐层评估

### L1 安装时 lint —— 做，且第一个做
- 用户看见：install/激活前体检报告（可路由性 ✓ / 缺 triggers ⚠ / 软措辞 ⚠ / 缺 when-not-to-use ⚠）。
- 唯一在决策现场给答案的层；补上 gate36 刻意不覆盖的"内容质量"线；gate31 TODO 槽位提供现成空壳信号（30 天未填=空壳）。
- 约束：lint 必须是建议性徽章不是闸；每条 finding 一行白话，禁止规则编号/内部术语。

### L2 观测记分卡 —— 做，但砍掉一半指标
- 瘦身到三个可见事实：**30 天触发次数（及趋势箭头）、显式反馈原始计数（正/负，不算比率）、L1 内容分**。其余收进 `vibe skill show <id>` 证据抽屉。
- 呈现纪律：事实句（"近 30 天被路由命中 3 次"），禁用 fire rate/hijack 等术语。

### L3 消融回放 —— 推迟，降级为按需诊断工具
- 回放回答"路由差异"不是"用户价值"；只在争议时刻有用，常设化=报告堆积=队列被淹没 2.0。
- 形态：`vibe skill audit <id> --replay`，一页 diff 报告；劫持率只活在这里，改名"争议命中"，只列样例不算比率。

### L4 活体基准集 —— 移出产品范围
- 用户不可见；标注腐化后制造 CI 假红。仓内 tier3 模式维持现状即可，不产品化。

## 2. 指标逐个挑战
- **fire→成功率：删掉，展示原始计数**。窗口短=沉默≠满意（自欺）；窗口长=归因稀释；显式反馈稀疏（多数技能 30 天个位数），按 <30 纪律永远"样本不足"，永久灰色 UI 就是死重。"2 次点赞/1 次纠正"是事实，"成功率 66%"是自欺。
- **"从未 fire"≠死重**：session-end/release 类天然低频高价值；窄触发技能从不 fire 是设计使然。联合判据：从未触发 + promote 召回验证 PASS 才可疑；从未触发 + WARN/窄触发是合理低频。只陈述事实组合，处置永远人审，绝不设自动降档。
- **劫持率：从记分卡删除**。兜底技能职责就是接模糊 query；回放拿"观察到的路由"当金标准是循环论证；名字过不了"看不懂表格列"关。降级为 L3 报告里的"争议命中"样例。
- **衰减度：推迟**，趋势箭头先顶着。

## 3. 四层之外更值得先做的形态
**`vibe skill list` 加一列健康摘要**应是最先交付物：该屏已有健康叙事雏形（stale 计数、all healthy 汇总行），加列零新认知负荷。列内容：`来源(market/promote/手工) · 体检✓/⚠ · 30天触发 N 次`。加 install 时刻内联 lint 报告。两个形态覆盖痛点两场景：装时知道好不好、装完知道哪些可疑。

## 4. 优先级与阶段
- **P0：L1 lint + skill list 健康列**。验收：① 用户不借助其他命令能指出哪几个技能可疑、为什么；② 每条 lint finding 一行白话；③ 零自动动作。
- **P1：L2 瘦身记分卡**。读取时从日志派生的 read-model 优先（只有性能出问题才加缓存）。验收：① 能回答"promote 的技能激活后有没有被用、反馈如何"；② 全仓 grep 不出自动降级路径挂记分卡；③ 无任何"成功率"口径百分比。
- **P2：L3 按需回放**。验收：报告全是"query → 含X/摘X 各路由给谁"具体列表，无汇总定罪分数；末尾固定先例文案。

## 5. 应砍/应推迟
- 砍 L4（产品范围外）；砍 fire→成功率与劫持率（指标级）；推迟衰减度与 L3 常设化。
- **永久边界**：任何基于记分卡的自动降级/删除路径永不做，上限是 gate35 式"--yes 确认+先例文案"批量建议。
- 跨层提醒：最大失败模式是又造一个用户要学习的屏幕。交付物形态排序：已有命令输出列 > show 证据区 > 一次性报告 > 新看板页面。前三个装得下绝不开第四个。
