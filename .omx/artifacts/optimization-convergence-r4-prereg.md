## 1. 触发条件（复检门槛，全条满足才开跑）

## 3. 判据（写死）

- **可分离**：存在阈值 `t` 使 **FPR ≤ 0.10 且 FNR ≤ 0.30** → 判为「已标定」，取该 `t`（多个可行时取 FNR 最小者；平手取 FPR 最小者）。
- **不可分离**：无可分离阈值 → 判为「证据仍不足」或「降级 advisory」（由人工选定并在报告写明理由）。
- **FPR / FNR 定义**（写死，防事后挪动）：
  - 正例对 = 同簇两条 trace；负例对 = 跨簇两条 trace。
  - 以「相似度 ≥ t 判为同簇」为预测：`FPR` = 负例对被判同簇的比例；`FNR` = 正例对被判不同簇的比例。
- **口径**：主口径 = **folded**（生产口径，连续同名折叠）；unfolded 作为对照**必须同时报告**，以量化折叠带来的方向性偏差（前序已实测一例 0.5 → 1.0）。
- **防泄漏（沿用前序纪律）**：同一 trace 的任何配对不进正例也不进负例；同一 cluster_id 的重复池行不参与正例自配。
- **聚合方式**：mean of pairwise Jaccard 为本轮固定选择（前序已在代码注释记录理由）；若要改，须作为独立实验，不在本轮偷改。

1. **样本量是最大约束**：前序 `28` 条候选只出 `2` 条序列。即使门槛满足，`≥30` 对仍是小样本，
   CI 会宽；结论须标注为"初步标定"，并给出样本量到达何值可望收窄。
2. **簇标签质量即标注质量**：正负例来自 M2 聚类结果，聚类若有误，FPR/FNR 一并失真。
   本轮**不**评估聚类质量，须在报告中声明该依赖。
3. **producer 形状混杂**：`tool:Read`（新）与 `tool: read_file`（旧）两种形状已被 `_tool_name`
   归一，但旧 producer 的单工具 span 占比高（前序 7/10 条 trace），可能系统性压低有效序列数。
