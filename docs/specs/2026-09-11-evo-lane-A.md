## 姿态

保留 hermetic 第 1/2/6 步（cwd/HOME→tmp、pin 候选宇宙）。放开第 3/4 步：不 null `load_sentence_transformer`，`enable_embedding=True`。AI triage **默认仍关**（提案写可开，但本轮先只开 embedding，避免把 LLM 方差叠进去）。SCENARIO 维持 pin 空。

另：`HF_HOME` 指本地缓存；`OMP_NUM_THREADS=1`；若能 import torch 则 `torch.set_num_threads(1)`。

控制组：同一 harness 把 embedding 再关掉，跑同样 N 次，稳定度必须恰为 1.0，否则 BLOCKED（测到的是 harness 噪声）。

N=10。题集：先 `tests/benchmark/routing_eval.yaml`（主集）。扩展集本轮可选，不要默默跑 oneshot/retention。

指标：每题 top-1 稳定度 = 众数 primary 次数 / N；layer 稳定度同式。JSON 必须记录 N、env pin、torch/HF 版本、线程设置。

## 成功 / 证伪（写进 handback，不要编）

- 控制组稳定度 ≠ 1.0 → 证伪 (a)，停，修 harness
- 语义层稳定度 ≈ 1.0 → 证伪 (b)，降级为低频抽检建议，不要再加预算
- 否则：交出首个数字化画像

缺 embedding 模型 / 离线失败：Status PARTIAL，把「无法验证」写清楚。不要假装跑过。
