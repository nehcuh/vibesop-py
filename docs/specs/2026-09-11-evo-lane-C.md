## 解析器行为

输入：一个文件或目录。输出 JSON（stdout 或 `--out`）。

每条 finding：

```json
{
  "gate": "gate1",
  "reviewer": "claude",
  "severity": "P1",
  "title": "normalized title",
  "raw_title": "原始标题",
  "source": "path"
}
```

标签映射（必须双套）：

| 原文 | severity |
|---|---|
| `[P0]` / `P0` | P0 |
| `[P1]` / `P1` / `MAJOR` | P1 |
| `[P2]` / `P2` / `MINOR` | P2 |
| `[nit]` / `NIT` / `NITS:` 下列项 | NIT |

文件名推断：`gate1-review-claude.md` → gate=`gate1`，reviewer=`claude`；`gate10-claude.md` → gate=`gate10`，reviewer=`claude`；`gate34-synthesis.md` → reviewer=`synthesis`。推不出就 `unknown`，不要崩。

标题归一化：小写、去标点、去路径片段（`src/foo/bar.py:12` → 去掉路径留语义词）。用于去重键。

去重（在一次运行的全集上）：

- 精确匹配（归一化标题完全相等）→ 保守下界
- token Jaccard ≥ 0.8 → 上界

输出摘要：

- `files_scanned` / `files_with_zero_findings`（覆盖率：抽到 0 条的文件数；这些可能是真的无 finding 或解析失败，要在摘要里分开列出文件名）
- `n_raw` / `n_unique_exact` / `n_unique_jaccard`
- `repeat_rate_low` = 1 - n_unique_exact/n_raw（n_raw=0 则 null）
- `repeat_rate_high` = 1 - n_unique_jaccard/n_raw
- 按 severity 分层的同样一组数
- **观察性声明**必须打印：`observational: true`；禁止输出因果句

CLI：`uv run python scripts/parse_gate_findings.py --root .omx/artifacts --glob 'gate*.md' --json-out PATH`

默认不要扫描整个 `.omx/artifacts` 在测试里；测试只用 fixture。
