## 对原稿和旧文章作出的边界修正

- R5 是有留白的题目，23.5 是静态审读总分；不写成“任务书太完整所以打平”。
- R6 不称“技能组获胜”，不称“静态脚手架已证明有效”。保留三次/两次尝试、runner 参数时点不全和事后豁免；严格规则下无有效评分。
- 路由 0.95 是匹配分数，不是经过标定的正确率。“收工了”在图中标为期望；live JSON 抽取缺口不算实测产品成功或失败。
- R7 评委与检查协议一起改变，不能单独声称测出了模型评分方差。
- 评审五项 MAJOR 的严重度没有共判，不意味着五项实质问题都不重叠。A/B/C 中存在三项实质重叠与两项 C 独有。
- 画像 1.0 是稳定度，不是准确率；单机单进程，AI triage 关闭，使用适配器，不能代表产品历史路径，更不能代表当前 bug 状态。
- 回声中的 91 是配对数。T+14 主指标正式回升结果保留；76 对集中一天有实测依据，CLI 调用进程来源尚有推断，不画成完整因果追踪。
- 本次只读核对历史报告，未重跑实验，也未把建议的三臂、重复盲评、产品复测写成已完成。
