# 大模型对着同一份代码，可以永远发现问题

> 一篇不打算卖课的实验笔记。所有数字都能在开源仓库里核对。

你一定见过这个场面。

AI 说：「本轮优化点已全部修复，仓库达到可发布状态。」你信了，合了，过两天换一个窗口、换一个模型、甚至只是再问一次「再审查一遍」，它又掏出一打 P1。

这不是你提示词写得差。这是这类系统的默认动力学。

我们在自己的项目里把这件事做成了可观测对象。结论先说：

**「再也发现不了新问题」在当前的 LLM 评审里，几乎不可能作为成功判据。能收敛的是决策，不是发现。**

---

## 一、现场物证，不是段子

同一天、同一个仓库，我们生成过四份彼此独立的优化计划：`optimization-plan.md`、`-p1`、`-p2`、`-auto-opt`。日期都是 2026-07-20。它们没有共享账本，没有去重，没有人问「第 4 轮相对第 1 轮，真实新增是多了还是少了」。

条目长这样：「给 `atomic_writer.py` 补测试」「把 `_shared.py` 拆开」。这类句子在任何还在长大的代码库里都不会自然终止。

后来我们又跑了 45+ 轮 gate 评审（claude / pi / grok 轮流上）。每轮都能交卷。把历史 gate 文件用**零模型**的文本解析器抽了一遍（2026-09-11，观察性，不是因果）：

- 扫到 191 个非 instructions 文件
- 抽出 310 条 finding
- 精确去重后 307 条，重复率大约 1%

注意：低重复率并不等于「都是新问题」。解析器只能看见标题像不像；它看不见「换一套词说同一件事」。我们用 10 个文件做了人工金标，结构化文件（`[P1]` 列表、`VERDICT/NITS` 代码块）条数对得上，半结构化散文对不上。所以这个 1% 是**标题字面重复的下界**，不是「伪影占比」。

伪影的上界，至今没有。这本身就是结论的一部分。

---

## 二、为什么它不会停

把「新发现」拆开：

```
观测到的新发现
  = 真新发现          （有限，本应几何衰减）
  + 改写型伪影        （每轮大致常数，无限）
  + 修复引入的新问题  （脉冲）
  + 标准漂移          （你换了评分口，旧代码变「新问题」）
```

再按可判定性分三类：

| 类 | 含义 | 有没有终点 |
|---|---|---|
| D | 编译/测试/lint 能判的违反 | 有 |
| T | 有测试或可观测行为作证 | 取决于覆盖 |
| J | 「可以更优雅」「建议拆分」 | **没有** |

任何没标 D/T/J 的「优化点计数」，都不能当门禁。多数 AI 评审输出的是 J，却用 D 的口气说话。

四条同时成立，「再也找不到新问题」才可能出现：问题集合有限可判定、评审确定性、上下文全覆盖、标准不漂移。我们这条链路里，四条都不成立。

所以正确的产品目标不是消灭新增，而是：

1. 把真新增和度量伪影分开；
2. 让**决策**收敛（这份 diff 今晚合不合），不要幻想**发现**收敛。

---

## 三、我们自己差点用「评审」当闸

Roadmap 写过一句禁令：不要把 LLM 评审当放行闸。很长一段时间，它只是文档。

2026-09-11 我们把它做成机制：CI 每个 job 必须登记 `decision_source: deterministic | human`。登记成模型输出的 required job，红灯。`routing-eval` 那份 JSON 给人看，标成 `human`，永不挡合并。

这不是洁癖。是因为我们发现：一旦把不可判定的 J 类输出接到 exit code 上，仓库会进入「永远修不完、永远合不了」的稳态。那不是质量，是仪式。

---

## 四、同一天的另一组数字

同一轮工作里，路由层倒是给出了可判定的数（Linux 容器里复跑过）：

- 题集 hermetic：过拒 4/31，过灌 2/20，近失负例过灌 2/14
- 生产 spans：898 次 `route:`，no-match 率 32.18%（Wilson 95% [29.2%, 35.3%]）
- 语义层 N=10 画像：控制组和 embedding 组稳定度都是 1.0——盲区不在「每次答案乱跳」，在「CI 根本没看见这一层」

这些数字能算，是因为它们是 D/T 类。gate 标题里的「建议重构」不算。

---

## 五、你明天可以做的三件事

1. **评审输出强制分类。** 没有 D/T/J 标签的条目，不当计数。
2. **账本先于发现。** 没有共享账本的第二轮「全面诊断」，默认当作新的幻觉生成器。
3. **机器闸只认机器。** lint、测试、hermetic 路由基线可以红灯；模型写的「P1 清单」最多标 human。

「AI 会永远帮你找到问题」听起来像产品卖点。量过以后，它更像是一种不会关机的噪声源。有用的部分是噪声里偶尔露出的 D 和 T。把它们捡出来，剩下的让它说，但别让它按合并键。
